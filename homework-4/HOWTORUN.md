# How to Run — Homework-4

## Prerequisites

- **Docker Desktop** (includes Docker Compose) — no local Go installation needed
- **Claude Code CLI** (`claude`) — required to run the agent pipeline
- An **Anthropic API key** set in your environment

---

## 1. Start the Application (Before Pipeline)

```bash
cd homework-4

# Start the service with the original hardcoded API key (bug still present)
API_KEY=supersecret-hardcoded-key-12345 docker compose up --build
```

The server starts on `http://localhost:8080`.

Verify the bug is present (returns local server time, not UTC):

```bash
curl -H "X-Api-Key: supersecret-hardcoded-key-12345" http://localhost:8080/time
```

---

## 2. Run the Pipeline

Each bug is processed independently. Open a new terminal in `homework-4/`:

```bash
./run-pipeline.sh context/bugs/bug001
./run-pipeline.sh context/bugs/bug002
./run-pipeline.sh context/bugs/sec001
```

Each run prints step-by-step progress and produces 6 artifact files:

```
context/bugs/<issue>/
├── bug-context.md               ← manually authored seed (input)
├── research/
│   ├── codebase-research.md     ← Bug Researcher output
│   └── verified-research.md     ← Research Verifier output
├── implementation-plan.md       ← Bug Planner output
├── fix-summary.md               ← Bug Fixer output
├── security-report.md           ← Security Verifier output
└── test-report.md               ← Unit Test Generator output
```

---

## 3. Run Tests Against Fixed Code

```bash
# Stop the running container first
docker compose down

# Run the test suite against the fixed source
docker compose run --rm app go test ./...
```

All tests should pass (including tests generated by the Unit Test Generator).

---

## 4. Restart the Application (After Pipeline)

After the sec001 fix the API key is read from the environment — set your own:

```bash
API_KEY=your-secret docker compose up --build
```

Verify the fixes:

```bash
# /time should now return UTC (Z suffix, not a local offset)
curl -H "X-Api-Key: your-secret" http://localhost:8080/time

# /health uptime should count up correctly (no overflow)
curl -H "X-Api-Key: your-secret" http://localhost:8080/health
```

---

## Environment Variables

| Variable | Default (docker-compose) | Description |
|----------|--------------------------|-------------|

| `PORT` | `8080` | Port the service listens on |
